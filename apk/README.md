# 📱 Android APK Releases

This folder contains pre-compiled, installable Android APK builds for **The Game Chest**.

### Latest Build:
- **File**: [`TheGameChest-debug.apk`](./TheGameChest-debug.apk)
- **Included Games**:
  1. *Rev-Up Racers: Turbo Circuit* (49-Tile Racing Board)
  2. *Save the Sheep! («Σώσε τα Προβατάκια»)* (40-Tile Meadow Board)
- **Requirements**: Android 8.0 (API 26) or newer.

### How to Install:
1. Download `TheGameChest-debug.apk` directly to your Android phone or tablet.
2. Open the file on your device and tap **Install** (allow "Install unknown apps" in Settings if prompted).
3. Open **The Game Chest** and enjoy playing!
